## Deploy to GitHub + Vercel
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Vercel, import the GitHub repository.
4. Framework preset: Other / static.
5. Build command: leave empty.
6. Output directory: `.` (repository root).
7. Deploy.
8. Add your custom domain if you have one.

## Google Search Console
After deployment:
1. Add your final domain/property to Search Console.
2. Verify ownership using the method Google provides.
3. Submit `/sitemap.xml`.
4. Use URL Inspection on the homepage and the article URLs.
5. Request indexing where appropriate.

Indexing cannot be guaranteed. Google decides whether and when pages are crawled and indexed.

## AdSense
This site is structured to be AdSense-ready, but approval is NOT guaranteed.
Before applying:
- replace the placeholder contact email
- customize Privacy Policy for your actual analytics/ads/cookie setup
- make sure all content is original and useful
- verify every link works
- add your real AdSense publisher line to `ads.txt` when Google provides it
- insert the AdSense code Google gives you (do not invent a publisher ID)

Do not buy fake traffic, clicks, impressions or use click-exchange/auto-surf services.

## SEO strategy
Do not stuff keywords into pages. Publish useful, original articles and build internal links naturally. Add more articles around real search questions related to Telegram bots, AI tools and market-analysis workflows.
